# Entrenamientos Java UF2

Repositorio con ejercicios prácticos desarrollados en **Java** correspondientes a la **Unidad Formativa 2 (UF2)**.

## 📘 Descripción
Este proyecto contiene aplicaciones en Java orientadas al uso de:
- Entrada de datos por consola
- Arrays
- Estructuras de control
- Cálculos y análisis de datos

En particular, se incluye una aplicación para el **registro y análisis de ventas diarias**, donde el usuario introduce el número de días y el importe de ventas de cada uno.

El sistema realiza automáticamente distintos cálculos y evaluaciones a partir de los datos introducidos.

## ⚙️ Funcionalidades
- Solicitud por consola del número de días a analizar
- Registro de las ventas diarias
- Cálculo del **total de ventas**
- Cálculo de la **media de ventas**
- Detección de:
  - Días con ventas superiores a **1000 €**
  - Días con ventas inferiores a **500 €**
- Análisis de la **tendencia de ventas**:
  - Creciente
  - Bajista
  - Estable
  - Con altibajos
- Clasificación del **rendimiento**:
  - Excelente
  - Regular
  - Malo
- Mostrar todos los resultados por consola

## 🛠️ Tecnologías utilizadas
- Lenguaje: **Java**
- Entrada de datos: `Scanner`
- Entorno: Consola
- Control de flujo: `if`, `for`, `while`
- Estructuras de datos: Arrays

## ▶️ Ejecución
1. Clonar o descargar el repositorio
2. Abrir el proyecto en un IDE (Eclipse, IntelliJ, VS Code)
3. Ejecutar la clase principal
4. Introducir los datos solicitados por consola

## 🎯 Objetivo formativo
Aplicar los conceptos básicos e intermedios de Java vistos en la UF2, reforzando la lógica de programación, el trabajo con arrays y el análisis de datos.
